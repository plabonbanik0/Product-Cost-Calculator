# Product Cost Calculator

A responsive browser-based business product cost calculator built with vanilla HTML, CSS, and JavaScript.

## Features

- Product, packaging, delivery, and shipment cost calculation
- Quantity-based order cost
- Profit margin calculation
- Suggested selling price
- Estimated total profit
- Cost breakdown
- Responsive design
- Print-friendly layout
- Bangladeshi Taka (৳) currency formatting

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

business-cost-calculator/
├── index.html

## Run Locally

Open `index.html` in any modern web browser.

No backend, database, package installation, or API is required.
